Приложение предназначено для автоматизации работы менеджера по организации мероприятий. 
Позволяет вести учёт клиентов, площадок, подрядчиков, задач, расходов и гостей, контролировать бюджет, формировать отчёты расходов и сохранять обратную связь от клиента. 
Интерфейс локализован на 4 языка (русский, английский, немецкий, китайский).
